# MGRAPPA
Code and Other docs related to the MGRAPPA algorithm: Motion Corrected GRAPPA for MRI
1. Create folder 'results'
2. Create and copy folder '20210313_MPREAGE'
3. Run in Matlab:
> MRI_grappa_motion_correction_MGRAPPA_PAPER.m

Program will generate 415 result files: 7 .csv 1.mat and 407 .jpg.  
81 .jpg files are created in the local folder; rest are saved in the 'results' folder
